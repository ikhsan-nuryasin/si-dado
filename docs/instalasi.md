# Instalasi SI DADO

1. Pastikan XAMPP atau Laragon sudah aktif.
2. Letakkan folder proyek di folder htdocs.
3. Buat database MySQL bernama sidado.
4. Jalankan file database/sql/schema.sql.
5. Jalankan file database/seed/seed.sql.
6. Sesuaikan konfigurasi database di config/config.php atau .env.example.
7. Akses aplikasi melalui http://localhost/sidado.
