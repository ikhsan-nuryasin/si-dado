# SI DADO

SI DADO adalah sistem informasi stok darah terpadu untuk Provinsi Jawa Barat.

## Fitur inti
- Landing page modern
- Login dan session management
- Dashboard admin
- Struktur MVC sederhana tanpa framework
- Basis untuk modul fasilitas, stok, sinkronisasi, distribusi, laporan, dan API

## Instalasi
1. Letakkan folder ini di htdocs
2. Buat database MySQL dengan nama sidado
3. Jalankan SQL dari database/sql/schema.sql
4. Jalankan SQL dari database/seed/seed.sql
5. Sesuaikan konfigurasi database di config/config.php
6. Akses http://localhost/sidado
